# Files preview security boundary

Files content comes from the authenticated, server-selected root and stays in native Views. The HTTP layer accepts only bounded JSON for source/list reads and byte-sniffed raster bytes for the image route. Relative Markdown/HTML images are normalized beneath the current document root, confirmed by the scoped Files/exist route, and passed to the shared authenticated image loader with the exact accepted read actor. The response bytes and MIME determine whether an extensionless or misleadingly named file is an image. Remote, data, absolute and root-escaping image references never create a request.

Markdown uses the existing `HistoryPresentation` block parser after a 1.1-million-character and 2,000-line gate. JSON is lexically depth/node checked before `JsonElement` construction, then projected iteratively with 5,000 rows, depth 64 and an output budget. HTML uses jsoup 1.23.2 with parser depth 64, a narrow Safelist, a 5,000-element limit and native heading/list/table/code/link/image blocks. Validated relative links, including contained cross-document heading fragments, pass through temporary safe parser sentinels, are restored only after cleaning, then require scoped Files/exist confirmation; external links receive no Collie credentials or native fetch. No WebView, DOM execution, form handling, CSS, remote loader or document URL is present. CSV is parsed with bounded rows, columns and cell length, including valid empty quoted cells. Every preview retains a Source view and localized refusal/truncation notices.

SVG uses AndroidSVG 1.4 only after a bounded pull-parser preflight. It refuses declarations, entity references, processing instructions, scripts, `foreignObject`, image/data references, `<use>`, styles, `href`, URLs and unknown elements/attributes. Input is limited to 1 MB, 10,000 elements, depth 64, 32 attributes per element, bounded path/scalar strings, dimensions and area, at most 12 nested transforms and 64 total transform functions. A finite Double affine 2×3 matrix composes each transform in the pinned parser's order and includes the supported root viewBox mapping; transformed coordinate envelopes and Float conversion are bounded before renderer parsing. Effective stroke paint inherits width/cap/join/miter alongside the affine stack; the shape envelope includes the transformed half-width, square-cap diagonal and declared/default miter limit before AndroidSVG parses the document. Only butt/round/square caps and miter/round/bevel joins with finite bounded width and miter scalars are admitted. Non-default preserveAspectRatio, nested viewports and SVG text/tspan refuse safely. Text is outside this supported subset because inherited font metrics and glyph advances are not covered by the geometric preflight; no SVG text reaches renderer parsing. `SVG.setInternalEntitiesEnabled(false)` is set before parsing. The renderer is used for ordinary viewBox mapping, nested transforms, inherited paint and pan/zoom; unsupported constructs refuse the preview and leave Source available. The allowlist and preflight remain required because AndroidSVG can parse internal entities by default and its renderer can decode embedded image data independently of the external file resolver.

In that snapshot, `SVG.java` has SHA-256 `40ce10aa6d08e251bb72b20983fda8662c5875c4e355383c5df7e27d90940362`, and `SVGAndroidRenderer.java` has SHA-256 `fbc0faec0470b7100c8afbc3a7cc74dc99676829b851f2dd1fcbb97bdbaf055e`. `SVG.setInternalEntitiesEnabled(false)` is process-global; this code does not rely on the setting as the parser boundary and never registers or deregisters a global file resolver.

The jsoup dependency is pinned to 1.23.2, its MIT license is included in the generated runtime dependency notice, and it is used only through in-memory parsing with an explicit safelist and depth/node caps. The implementation never calls `Jsoup.connect`, `Jsoup.parse(URL)`, or any network API. Relative URLs are interpreted only as same-root Files references after normalization and existence confirmation.

Source-level checks and local fixtures do not establish API 26/current-device behavior, memory pressure under real files, TalkBack/200% font usability, Crew mixed-version transport or successful SVG interoperability across the full SVG standard. Those remain acceptance checks; the renderer intentionally supports a reviewed subset and refuses the rest.

Printed reference extraction caps dispatched candidates at 64. If the bounded displayed text contains more than 64 absolute path starts, the entire text remains plain rather than allowing an unprotected later absolute token to be interpreted as a relative suffix. If an absolute token or complete spaced extension path exceeds the path/protection bound, or a quoted absolute span cannot be closed on the same line, the entire bounded text is inert; a colliding in-root basename cannot be extracted from that evidence. Tool expand/collapse rebuilds redecorate using the original accepted turn actor; detached disclosure callbacks cannot borrow a replacement renderer generation. Transcript absolute candidates enter root-backed discovery with their accepted actor; they acquire no click authority until root and scoped existence checks succeed. Rows, breadcrumbs and delayed span callbacks retain the page/actor that created them.

Transcript discovery accounts for at most 64 distinct paths in each rendered batch. Repeated tool rebuilds may freshly confirm those same paths without consuming additional slots; a new 65th path remains plain. Only an actual added/replaced turn batch or read-authority retirement clears this accounting: unrelated PaneUiState renders and unchanged accepted polls do not. A new turn batch freshly checks retained and new cards under each card's original accepted actor. Its generation prevents older awaited callbacks from reserving or publishing into the replacement batch. Mirror-only retirement does not reset transcript accounting; full lifecycle/authority retirement does. Reservation and clearing share a short local lock, with no network await or UI work inside it; every actual Files/existence request still uses the exact captured actor. Rediscovery removes only Collie's own confirmation spans before awaiting fresh evidence, preserving markdown links and formatting without accumulating old positive confirmations.

Files retirement tracks outgoing text and native preview Views weakly by their original actor, including detached copies. Listing ownership updates when a holder is rebound; retirement erases old names, accessibility text and listeners in detached and pooled holders without clearing replacement rows. SVG disposal releases the parsed graph and makes draw/touch inert. Raster requests, queued deliveries, versioned cache entries and card/viewer registrations retain their original actor; the loader observes committed encrypted-store changes and repository retirement without a fresh read. Retired entries cannot return to the cache. Main clears drawables and private descriptions before releasing active leases, outside image, storage, admission and ViewModel locks; only unpinned retired bitmaps recycle. Pending admission blocks dispatch but does not permanently destroy a still-current actor. Explicit loader shutdown remains a global lifecycle teardown. These source corrections require fresh native, independent whole review and actual format/device/Crew acceptance; earlier failed controlled runs remain preserved and open.

Committed connection custody includes an opaque ID encrypted in the existing connection envelope. The store atomically captures revision, ID and connection; successful save/clear increments the process revision, while failed persistence changes neither witness nor authority. The exact live instance retains its ID on recommit. Clear/reference replacement and A→clear/replacement→the original A receive a new ID. Coalesced observers run outside storage/admission/image/custody locks and inspect original actors against the current committed ID; Connection-flow reference equality cannot resurrect old views or handoffs. Snapshot CAS requires the original revision, ID and reference; lifecycle demotion may capture a newer revision only after proving the original ID/reference still owns it. Request custody carries the original actor through transport waits and checks it at the final network interceptor. Same-live recommits and temporary admission pauses preserve live allocations. Legacy encrypted records without an ID require explicit reconnect, with no authority minted by reads. Fresh native, independent whole review, canonical join and actual device/Crew/resource acceptance remain required.

### Pending acknowledgements and final operation admission

Existing held actor custody survives temporary pending admission. Genuine same-incarnation
scope/access acknowledgements refuse new actor allocation and block read, write, publication
and click gates until completion without permanently retiring that retained custody. Unsupported
stores retain the conservative no-new-actor pending contract. A new committed
incarnation does not inherit its predecessor's pending callback fence. Entry captures original
listeners, copied-custody identity and journal ownership; delayed predecessor completion removes
only its original pane cache and launch-journal entries. Journal cleanup derives its locked current
postimage and persists it before publication; a failure preserves encrypted disk bytes and makes
the store unavailable. Immutable retirement events compare each copied original actor again on
Main before cleanup, so refreshed B rows, bodies, dialogs, drafts and UNKNOWN recovery state
survive queued A callbacks on the same screen instance.
The original immutable actor and declared operation admission survive transport waits: ordinary
mutations recheck current snapshot write authority at the final network interceptor, while
paired device-owned preferences retain their existing read admission and access/offline fences.
No operation is automatically replayed. Current source native, canonical and actual device
acceptance remain pending; historical failed native/device evidence is retained.
