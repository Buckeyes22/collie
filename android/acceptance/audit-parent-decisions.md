## Deliberate runtime boundaries

Accepted Codex text is kept in memory, not persisted across process death. Legacy `/history`, slash commands, changed journal generations, transformed/attachment turns and missing baselines can require manual dismissal. Exact later text is correlation, not a causal delivery identifier; the HTTP contract exposes no such identifier and Codex's local queue is not surfaced by the journal. A consumed composer does not prove model dispatch. No automatic replay was added.

Current source review and synthetic transport/device tests do not establish real Codex queue behavior, physical radio/VPN handoff, OEM Keystore invalidation/restore, real recording/provider delivery, battery measurements, signed production artifact behavior or complete audible TalkBack traversal. Unsupported native push delivery/provider registration, full vendor SDK/protocol implementations, and unimplemented Files/Changes/server-only UI routes are explicitly outside the shipped native surface. Generated View Binding/serialization and third-party dependency internals are accounted for as build inputs, rather than claimed as hand-reviewed application source.
