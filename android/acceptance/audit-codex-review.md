## Findings and residual evidence gaps

No confirmed source defect was found in this bounded path, so no correction is proposed. Specifically, a successful initial typing RPC does not cause draft clearing; Android waits for a Codex composer readback carrying the submitted text, binds the observed rendered region, submits once through `submitReply`, and only clears the Android draft after the terminal composer is observed again. If the readback, submit, or consumption is ambiguous, it returns a visible unconfirmed result and keeps the draft; connection changes stop the multi-step sequence.

Behavioral evidence is strongest at unit/fixture level. The inspected tests do not establish a real installed Codex version’s exact paste timing, terminal emulator paste handling, mux transport latency, or on-device keyboard/paste behavior across the supported fleet. The source capture notes identify Codex versions 0.154–0.158, but not all current or user-installed builds. No live-device/live-server result was generated for this unit. Keep those items unresolved as runtime coverage limits, not code defects.
