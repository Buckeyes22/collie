- **The historical “truncated always false” claim has drifted.** Stable code computes `truncated` from omitted lines and has a test asserting true: [Herdr v0.9.3 src/app/api_helpers.rs:143](https://github.com/herdrdev/herdr/blob/v0.9.3/src/app/api_helpers.rs#L143), [Herdr v0.9.3 src/app/api/panes.rs:2786](https://github.com/herdrdev/herdr/blob/v0.9.3/src/app/api/panes.rs#L2786).
